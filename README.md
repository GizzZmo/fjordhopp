# Fjordhopp

Et 2D-plattformspill gjennom mosegrodde norske klipper i kveldslys.

Løp, hopp og dobbelthopp langs hyller. Samle mynter, aktiver sjekkpunkt, unngå pigger og reis flagget på toppen.

## Spill

- **Bevegelse:** A/D eller piltaster
- **Hopp:** Mellomrom, W eller pil opp. Hopp igjen i lufta for dobbelthopp
- **Fall gjennom hyller:** S + hopp
- **Nivåer:** Strandkanten, Fjellhylla, Toppflagget
- På telefon: Venstre / Høyre / Hopp nederst på skjermen

## Stack

TanStack Start, React, Canvas 2D, Tailwind CSS.

Bygget med Grok.
